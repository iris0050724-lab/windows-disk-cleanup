# 清理前备份核对表

**在删除或移动任何东西之前，逐项确认下列数据是否已备份。**

备份目标优先级：**另一块物理硬盘 > 移动硬盘 / U 盘 > 云端**。
**不要把备份放在正要清理的同一个盘上。**

---

## 1. 登录凭据 / 账号信息

- [ ] 浏览器保存的密码与自动填充数据
- [ ] 浏览器 Cookie / 登录令牌（导出或确认可重新登录）
- [ ] SSH 私钥 `%USERPROFILE%\.ssh\`（`id_rsa`、`id_ed25519` 等）
- [ ] Git 凭据 `.git-credentials`、`%USERPROFILE%\.gitconfig`
- [ ] 各软件的 API Key / Token 配置文件（`.env`、`config.json`、`credentials` 等）
- [ ] 云服务 CLI 凭据（`.aws`、`.azure`、`.kube`、`.config\gcloud` 等）
- [ ] 双因素认证（2FA）恢复码 / 备份码

## 2. 密码管理器

- [ ] KeePass `.kdbx` 数据库
- [ ] 其他本地密码库文件

> 密码管理器数据库一旦丢失且无备份，所有密码都将无法恢复。**最高优先级。**

## 3. 聊天 / 通讯记录

- [ ] 微信 `WeChat Files` / `xwechat_files`
- [ ] QQ 用户数据目录
- [ ] 企业微信 / 钉钉 / 飞书本地数据
- [ ] 其他 IM 工具的本地记录
- [ ] 若已在手机 / 云端有完整记录，确认后再决定是否清理本地

## 4. 软件日志与诊断数据

- [ ] 各 `AppData\...\logs` 目录
- [ ] 崩溃转储（若需要排查问题）
- [ ] 审计日志 / 操作日志（合规场景必须保留）
- [ ] 系统事件日志（必要时导出 `.evtx`）

## 5. 授权 / 许可证

- [ ] `.lic` / `.key` / 激活码文件
- [ ] `C:\ProgramData\<厂商>` 下的许可证目录
- [ ] 软件购买凭证、序列号记录
- [ ] 正版授权绑定的机器码信息

## 6. 配置文件

- [ ] 编辑器 / IDE 配置（`.vscode`、`.idea`、各 IDE 的 settings）
- [ ] `.workbuddy`、`.claude`、`.config` 等工具配置
- [ ] 各软件的 `config` / `settings` / `preferences`
- [ ] 自定义快捷键、宏、脚本

## 7. 证书与密钥库

- [ ] `.pem` / `.p12` / `.pfx` / `.key`
- [ ] 代码签名证书
- [ ] 客户端证书

## 8. 浏览器数据

- [ ] 书签（导出为 HTML）
- [ ] 扩展及其配置
- [ ] 历史记录（如需）

## 9. 邮件

- [ ] `.pst` / `.ost` / `.olm` 本地邮件数据
- [ ] 本地草稿、已发送邮件的本地副本

## 10. 数据库与工程文件

- [ ] 本地数据库 `.db` / `.sqlite` / `.mdb`
- [ ] 未提交的代码（`git stash` / 未 commit 的改动）
- [ ] `.git` 目录（本地仓库未推送的提交）
- [ ] 设计稿、工程文件（`.psd`、`.ai`、`.fig` 本地文件）

## 11. 云盘 / 同步目录

- [ ] 网盘本地目录中**尚未上传**的文件
- [ ] 同步客户端的本地缓存中可能存在的独占文件
- [ ] 确认同步已完成（无"正在同步"状态）

---

## 完成后

1. 至少抽查 2 – 3 个备份文件可以正常打开。
2. 记录备份位置与时间。
3. 再进入清理 / 迁移流程。

> **再次提醒：因清理导致的重要文件丢失，本技能的作者与分发者不承担责任。备份是你的责任。**
